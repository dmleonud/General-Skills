# Cylab CTF Writeups

A collection of solved Capture The Flag (CTF) challenges and writeups, maintained by **Cylab**.

This repository documents challenges we've solved across various CTF competitions, organized by category and event. Each writeup includes the challenge description, our approach, the tools used, and the full solution.

## 📁 Repository Structure

```

├── 2026/

│   ├── event-name-ctf/

│   │   ├── web/

│   │   ├── crypto/

│   │   ├── forensics/

│   │   ├── pwn/

│   │   ├── reverse-engineering/

│   │   ├── misc/

│   │   └── osint/

│   └── ...

├── resources/

│   └── tools-and-cheatsheets.md

└── README.md

```

Each challenge folder typically contains:

- `README.md` — the writeup (challenge description, solution steps, flag)

- Supporting files (scripts, payloads, screenshots) used to solve the challenge

## 🏆 Categories Covered

| Category | Description |

|---|---|

| Web Exploitation | SQLi, XSS, SSRF, auth bypass, and more |

| Cryptography | Classical and modern crypto challenges |

| Forensics | Memory dumps, network captures, file analysis |

| Binary Exploitation (Pwn) | Buffer overflows, ROP chains, etc. |

| Reverse Engineering | Static/dynamic analysis of binaries |

| OSINT | Open-source intelligence gathering |

| Misc | Steganography, scripting, trivia |

## 📝 Writeup Format

Each writeup follows a consistent format:

```md

# Challenge Name

**Category:** Web / Crypto / Pwn / etc.

**Difficulty:** Easy / Medium / Hard

**Points:** XXX

**Event:** CTF Name YYYY

## Description

> Original challenge description/prompt

## Solution

Step-by-step explanation of the approach and reasoning.

## Flag

`flag{...}`

```

## 🎯 Purpose

This repository serves as:

- A knowledge base for Cylab members to review past solves

- A training resource for newer members preparing for competitions

- A public record of our team's CTF participation and progress

## 🤝 Contributing

Cylab members are welcome to add writeups for challenges they've solved:

1. Fork or branch from `main`

2. Create a folder under the appropriate `year/event/category` path

3. Add your writeup following the format above

4. Submit a pull request for review
